# Credits

This project builds on data and tooling from the following sources.

## Data sources

- **[geoBoundaries](https://www.geoboundaries.org/)** - open, standardized administrative boundary
  data for countries worldwide, published by the geoLab at William & Mary. Used here as the
  geometry source for administrative zones.
- **[GeoNames](https://www.geonames.org/)** - geographical database covering all countries,
  distributed under a Creative Commons Attribution 4.0 license.
- **[INSEE](https://www.insee.fr/)** (Institut national de la statistique et des etudes
  economiques) - official French administrative division reference data (regions, departements),
  used as the canonical source for metropolitan France.
