# geo_data

Télécharge et normalise les données de découpage administratif (INSEE, geoBoundaries, GeoNames)
au format GeoJSON attendu par GeoChallenge-Tracker.

Voir `scripts/README.md` pour le pipeline téléchargement/normalisation/export,
`scripts/docs/CONTRACT.md` pour le schéma de sortie, et `CREDITS.md` pour l'attribution des
sources de données.
